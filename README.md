# learning_input

学習記録・学習教材のリポジトリ。
各分野ごとにディレクトリを分け、理論の理解から実践への応用までを体系的に蓄積する。

---

```
learning_input/
├── README.md
├── learning_science/    認知科学・教授設計・学習理論
├── engineering/         ソフトウェアエンジニアリング
└── ...                  今後追加予定
```

## 運用ルール

### ブランチ命名規則

```
study/<分野>/<トピック>

例：
  study/learning-science/clt-basics
  study/engineering/system-design
```

### ディレクトリ構成の原則

- 各分野のディレクトリ直下に `README.md` を置き、その分野の学習マップ・進捗・参考文献を管理する
- 学習ノートは分野ディレクトリ配下の `notes/` にまとめる
- 原典文献の要約は文献ごとに独立したファイルとして作成する（例：`author_year.md`）

### 進捗管理

各分野の `README.md` 内の状態表記を以下の3段階で統一する：

| 表記 | 意味 |
|---|---|
| `[学習中]` | 現在進行中 |
| `[未着手]` | 今後学ぶ予定 |
| `[完了]` | 一通り学習済み（随時更新） |
